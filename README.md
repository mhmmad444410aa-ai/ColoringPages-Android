# Coloring Pages — Android

مشروع لعبة التلوين `com.mhmmad.coloringpages` (إصدار 1.2.0) المجهّز للتجميع بواسطة GitHub Actions.

تُرفع حزمة المصدر باسم `ColoringPages_1.2.0_HuaweiAds_Source.zip` إلى جذر هذا المستودع. لا ترفع ملف مفتاح التوقيع أو كلمات المرور إلى مستودع عام؛ استخدم GitHub Actions Secrets فقط.

نظام البناء يقوم بتجميع إصدار APK/AAB موقّع بعد إضافة أسرار التوقيع الصحيحة، ويطابق بصمة شهادة الإصدار 1.1.0 حتى يكون قابلاً للتحديث.
